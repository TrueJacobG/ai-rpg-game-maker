# Roadmap

**Status: living document.**

## Build order

1. Foundation: repo, docs, tooling.
2. `packages/core`: dice, ruleset engine, schemas.
3. Worker and D1: auth for master, prompter pairing, player tokens, characters and items.
4. Realtime session: Durable Object, phases, prompter screen with the mic indicator, decisions.
5. World pack import and export, sample pack.
6. AI provider interface, next-beat suggestions, recaps.
7. Plot graph and bridge scenes.

## Not designed yet

- Map: where the party is.
- Image generation for quests and scenes.
- Story visualization, for example a timeline or relationship graph.
- Gamification: XP, achievements, faction reputation.
- Decisions from player phones.
- Per-player decisions instead of group decisions.
- Optional Whisper transcription on Workers AI as a fallback to browser speech recognition.
